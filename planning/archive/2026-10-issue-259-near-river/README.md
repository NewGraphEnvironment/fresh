## Outcome

fresh 0.41.0 adds the `near_river: {discharge_min, distance_max}` rule condition (#259): a segment that fails a rule's size test passes when a river of at least `discharge_min` m³/s lies within `distance_max` m downstream, measured from the segment's downstream end to the river's bank. The loader validates the key, the compiler ORs the size test with an `EXISTS` on a distance table, and `frs_habitat_classify()` builds that table with the new exported `frs_near_river()`, one walk per distinct pair. Most of the work went into the walk. A live check on BULK against an independent route-measure walk, then six code-review rounds, found nine ways the obvious windowed `FWA_Downstream()` walk reads wrong. Each is fixed and pinned by a fixture test with a planted-defect check: stretches outside the table counted as nothing; tributaries meeting a parent mid-row counted the whole row; an out-of-step local code put an upstream row on the origin's own line; rows with no local code walked through a branch that ignores it; jumps across dry land subtracted as bank; several polygon entries exceeding the cap; and a prefilter that could drop a row reached by a jump, so one rule's answer could depend on another's. The durable FWA facts are in `research/fwa_downstream_walk.md`.

## Measurement

BULK at 3 m³/s on wet's annual pick (fresh `b616b44`, the final logic; `d12b686` changed docs and a guard only):

- **Walk time:** 16 s at 1 km, 73 s at 20 km on 32,472 segments. That was 7 s and 28 s before the review rounds' path checks.
- **Segments measured:** 2,118 within 1 km, 22,523 within 20 km. None is negative. The 1 km and 20 km walks agree on every segment within 1 km.
- **Against the independent walk, 2,462 sampled segments:**
  - agree 614, to within 0.003 m;
  - bank rule only 1,169, with no bank distance shorter than the straight line to the polygon;
  - beyond 20 km 440;
  - entry point differs 225, longer in all but 6, which are 14 to 67 m shorter;
  - nested local code 14;
  - unexplained 0.
- **Coffin Creek, link#364's example:** its wetland segments are 4.6 to 12.3 km from a 3 m³/s river, so they fail at 1 km.

**Wrong turns kept.** The first BULK run read 183 negative distances. These were floating-point residue. It also found 127 segments within 1 km at a 20 km reach that the 1 km walk missed: a 17.8 km stretch outside the group had read as 973 m. Three plan assumptions did not hold:

- that rows with no local code are absent from the working table;
- that connectors always lie on the walked line;
- that the longest connector run per polygon bounds the subtraction.
